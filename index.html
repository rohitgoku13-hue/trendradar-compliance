API service disclosure

Built with public data

Trend Radar uses the YouTube Data API v3, including search.list, videos.list, and channels.list.

Trend Radar uses YouTube API Services. It is independent and is not affiliated with or endorsed by YouTube or Google.

What Trend Radar does

Factual, deterministic public-data research.

Public metadata analysis

We analyze available public video and channel metadata such as titles, publication times, public view counts, engagement counts, duration, category information, and subscriber observations where available.

Deterministic filtering

Eligibility and evidence rules are applied consistently. Derived metrics are generated by Trend Radar from collected public metadata.

Data minimization

Trend Radar requests only the API data needed for its analytics and research workflow. It does not collect user passwords and currently does not require end-user Google sign-in.

How data is handled

Research, not media collection.

Trend Radar does not download YouTube videos, does not scrape YouTube webpages, and does not acquire video, audio, frames, or transcripts as part of this public-metadata workflow.
